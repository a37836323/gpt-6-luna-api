使用兼容客户端时，配置 base_url、api_key 和模型名，并逐项核对接口与参数兼容性。

  1. 确认账户分组：先确认账户当前所在分组及其倍率。实际价格按 gpt-6-luna 基准价乘以该倍率计算。
  2. 确认 API 接入参数：向服务方确认请求地址、鉴权方式、模型标识和请求格式。现有资料没有提供这些参数，不应直接套用未经确认的接口示例。
  3. 核对价格数据：可查看面板定价接口 https://api.openlux.ai/api/pricing 中的模型定价信息；该接口是面板自身的定价接口，不是已确认的模型调用接口。
  4. 准备最小调用测试：取得服务方给出的接入文档后，按文档配置凭证并发送最小请求，检查模型标识、返回格式和错误信息。
  5. 检查计费结果：用实际请求记录核对 token 用量、基准价格和分组倍率；若计费口径不一致，联系服务方确认。
